## The contrast between the two backends

| | deterministic | model-backed |
|---|---|---|
| reranking changes recall@5 | 0.8987 -> 0.9620 | 1.0000 -> 1.0000 |
| reranking changes mrr | 0.8006 -> 0.8911 | 0.9610 -> 0.9523 |

**Reranking helps exactly when retrieval leaves it room to.** Under hashing embeddings the candidate set is poor, so a cross-encoder has something to fix; under real embeddings the candidate set is already good and reordering can only shuffle a saturated top-5. Neither run is "the system" - each is a measurement of one backend on one corpus, so this verdict must be re-measured after any corpus or embedding change rather than inherited.
